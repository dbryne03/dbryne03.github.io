# GCP Data Integration & Dimensional Modeling

*This page is currently a placeholder and will be populated as Task 2 progresses.*

## Overview
This project simulates a complex partner-facing integration scenario requiring custom extraction, event-driven staging, and rigorous transformation into a dimensional data warehouse on Google Cloud Platform.

### Planned Tech Stack
- **Ingestion:** Custom Python REST API Clients
- **Event Streaming:** GCP Pub/Sub
- **Storage:** Google Cloud Storage (GCS)
- **Data Warehousing:** Google BigQuery
- **Transformation:** dbt Core
- **Orchestration:** Apache Airflow
