# Azure CDC Migration Validation Framework

*This page is currently a placeholder and will be populated as Task 3 progresses.*

## Overview
This project develops an enterprise-grade Change Data Capture (CDC) migration and validation framework on Microsoft Azure. It demonstrates the programmatic guarantee of data integrity across complex enterprise environments.

### Planned Tech Stack
- **Orchestration:** Azure Data Factory (ADF)
- **Validation Engine:** Python (Hashing) and T-SQL
- **Storage:** ADLS Gen2 and Azure SQL Database
